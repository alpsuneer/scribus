വാർത്ത ബ്രൗസർ (News Browser)

Newsroom-ലെ വാർത്തകൾ നേരിട്ട് Scribus-ലേക്ക് കൊണ്ടുവരാനുള്ള panel ആണിത്. Copy-paste ചെയ്യാതെ, edition അനുസരിച്ച് വാർത്ത തിരഞ്ഞെടുത്ത് text frame-ൽ നേരിട്ട് ഇടാം. Paragraph Styles docker-ന്റെ മൂന്നാമത്തെ tab ആയി ഇത് വരും.

Connect ചെയ്യാൻ

ഇത് ഒരു web API വഴിയാണ് വാർത്ത എടുക്കുന്നത് — database-ലേക്ക് നേരിട്ടുള്ള connection അല്ല. അതുകൊണ്ട് server / username / password എന്നിവ ഇവിടെ ചോദിക്കില്ല. വേണ്ടത് ഒരു API URL മാത്രം.

  1. Panel-ന്റെ മുകളിലുള്ള ⚙ (Settings) button അമർത്തുക.
  2. Password ചോദിക്കും — ഇത് system administrator-ന്റെ പക്കൽ ഉണ്ട്. തെറ്റായ password ആണെങ്കിൽ settings തുറക്കില്ല.
  3. API URL കൊടുക്കുക (workflow server-ന്റെ വിലാസം). ഇത് ഒരിക്കൽ set ചെയ്താൽ മതി; അടുത്ത തവണ ഓർത്തുവയ്ക്കും.
  4. വേണമെങ്കിൽ ഒരു default edition കൊടുക്കാം — എന്നും ഒരേ edition-ൽ ജോലി ചെയ്യുന്നവർക്ക് സമയം ലാഭിക്കാൻ.

ശരിയായോ എന്ന് എങ്ങനെ അറിയാം: settings അടച്ചതിനു ശേഷം Edition dropdown-ൽ edition-കളുടെ പേരുകൾ വരും. താഴെ status വരിയിൽ ഏത് edition ആണ് ഉപയോഗിക്കുന്നത് എന്നും കാണിക്കും. Dropdown ശൂന്യമാണെങ്കിൽ connect ആയിട്ടില്ല.

ഉപയോഗിക്കുന്ന രീതി

  1. Edition തിരഞ്ഞെടുക്കുക.
  2. Page തിരഞ്ഞെടുക്കുക.
  3. Date — സ്വതവേ നാളത്തെ തീയതി വരും; വേണമെങ്കിൽ മാറ്റാം.
  4. Fetch News അമർത്തുക. താഴെ വാർത്തകളുടെ list വരും.
  5. ഒരു വാർത്തയിൽ click ചെയ്താൽ അതിന്റെ preview കാണാം.
  6. വേണ്ട വാർത്തകൾ checkbox ഇട്ട് തിരഞ്ഞെടുക്കുക (എല്ലാം വേണമെങ്കിൽ Select All).
  7. ഏത് text frame-ലേക്കാണ് വേണ്ടത് എന്ന് canvas-ൽ select ചെയ്യുക.
  8. Place Selected അമർത്തുക — വാർത്ത frame-ൽ വരും. ചിത്രം ഉണ്ടെങ്കിൽ അതും വരും, text wrap സഹിതം.
ശ്രദ്ധിക്കുക: Place ചെയ്യുന്നതിനു മുൻപ് text frame select ചെയ്തിരിക്കണം. ഒന്നും select ചെയ്തിട്ടില്ലെങ്കിൽ വാർത്ത എവിടെ ഇടണമെന്ന് Scribus-ന് അറിയില്ല.

പ്രശ്നങ്ങളും പരിഹാരവും

Edition dropdown ശൂന്യം / "connection refused"
⚙ Settings-ലെ API URL ശരിയാണോ എന്ന് നോക്കുക. Network ഉണ്ടോ എന്ന് നോക്കുക. Server പ്രതികരിക്കാൻ 5 സെക്കൻഡ് മാത്രമേ കാത്തിരിക്കൂ — server പതുക്കെയാണെങ്കിൽ വീണ്ടും 🔄 Refresh അമർത്തി നോക്കുക.

Fetch ചെയ്തിട്ടും list ശൂന്യം
ആ edition-ൽ, ആ page-ൽ, ആ തീയതിക്ക് വാർത്ത ഇല്ല എന്നാണ് അർത്ഥം. Date ശരിയാണോ എന്ന് ആദ്യം നോക്കുക — സ്വതവേ നാളത്തെ തീയതിയാണ് വരുന്നത്, ഇന്നത്തേതല്ല. എന്നിട്ട് edition, page മാറ്റി നോക്കുക.

അക്ഷരങ്ങൾ തെറ്റി വരുന്നു / ചതുരക്കട്ടകൾ കാണുന്നു
വാർത്ത ശരിയായി വന്നിട്ടുണ്ട്, പക്ഷേ frame-ന്റെ font-ന് മലയാളം അക്ഷരങ്ങൾ ഇല്ല. Text frame-ന്റെ paragraph style-ൽ ഒരു Malayalam Unicode font (ഉദാ: DBI Text) കൊടുക്കുക. Copy ചെയ്ത് വേറെ എവിടെയെങ്കിലും ഒട്ടിച്ചാൽ അക്ഷരം ശരിയാണെങ്കിൽ പ്രശ്നം font ആണ്, വാർത്തയല്ല.

Place Selected അമർത്തിയിട്ട് ഒന്നും സംഭവിക്കുന്നില്ല
Text frame select ചെയ്തിട്ടുണ്ടോ? ഒന്നിലധികം object select ചെയ്തിട്ടുണ്ടെങ്കിൽ ഒരെണ്ണം മാത്രമാക്കുക.

Styles tab

Document-ലെ എല്ലാ paragraph style-കളും ഇവിടെ കാണാം. Style-ന്റെ പേരിൽ click ചെയ്താൽ, cursor നിൽക്കുന്ന paragraph-ന് (അല്ലെങ്കിൽ select ചെയ്ത paragraphs-ന്) ആ style apply ആകും.

തിരയാൻ

മുകളിലെ Search styles… box-ൽ ടൈപ്പ് ചെയ്താൽ list ചുരുങ്ങും. നൂറിലധികം style ഉള്ള newspaper document-ൽ ഇത് വേഗത്തിൽ എത്താൻ സഹായിക്കും.

Chain icon — Next Style

ചില style-കളുടെ വലതുവശത്ത് ഒരു chain icon കാണാം. ആ style-ന് ഒരു next style നിശ്ചയിച്ചിട്ടുണ്ട് എന്നാണ് അതിന്റെ അർത്ഥം — ഉദാഹരണത്തിന് 07 Byline-ന് ശേഷം 01 Dateline, അതിനു ശേഷം 03 BodyNoInd.

Chain icon ഉള്ള ഒരു style-ൽ click ചെയ്താൽ, ആ chain തുടർച്ചയായ paragraphs-ന് ഒരുമിച്ച് apply ആകും: ആദ്യത്തെ paragraph-ന് തിരഞ്ഞെടുത്ത style, രണ്ടാമത്തേതിന് അതിന്റെ next style, എന്നിങ്ങനെ. ഒരു headline block മുഴുവൻ ഒറ്റ click-ൽ format ചെയ്യാം.

Chain apply മുഴുവൻ ഒറ്റ undo step ആണ് — തെറ്റിയാൽ ഒരു Ctrl+Z മതി, ഓരോ paragraph-നും വെവ്വേറെ വേണ്ട.

Style shortcuts

ഓരോ style-നും keyboard shortcut കൊടുക്കാം. Panel-ലെ settings-ൽ Set Key അമർത്തി key അമർത്തുക. അതിനു ശേഷം text-ൽ എവിടെയായാലും ആ key അമർത്തിയാൽ style apply ആകും.

ഒരേ key രണ്ട് സ്ഥലത്ത് കൊടുത്താൽ Scribus ഒന്നും ചെയ്യില്ല (രണ്ടും fire ചെയ്യില്ല). അങ്ങനെ വന്നാൽ Preferences → Keyboard Shortcuts-ൽ പോയി conflict പരിഹരിക്കുക — ഏത് action ആണ് ആ key കൈവശം വച്ചിരിക്കുന്നത് എന്ന് അവിടെ കാണിക്കും.

Design Style tab

ഒരു വാർത്തയുടെ മുഴുവൻ രൂപവും ഒറ്റ click-ൽ ഉണ്ടാക്കാനുള്ള preset ആണിത്. ഓരോ Design Style-ലും ഇവ ഉൾപ്പെടാം:

  • തുടർച്ചയായ paragraphs-ന് കൊടുക്കേണ്ട style sequence (ഉദാ: headline → byline → dateline → body)
  • ഏത് style-ന് ശേഷം column break വരണം
  • Frame-ന്റെ column config — എത്ര column, gutter എത്ര
  • ഒരു image frame വേണോ, വേണമെങ്കിൽ എവിടെ (ഇടത്/വലത്/മുകളിൽ), text wrap സഹിതം
  • ചിത്രത്തിന് ഒരു caption frame

ഉപയോഗിക്കാൻ: text frame select ചെയ്യുക, എന്നിട്ട് Design Style-ന്റെ button അമർത്തുക. Style-കൾ, column break, column config, image frame, caption frame — എല്ലാം ഒരുമിച്ച് വരും.

Preset-കൾ ഉണ്ടാക്കാനും മാറ്റാനും tab-ലെ settings button ഉപയോഗിക്കുക.

Paragraph Rules — വരകൾ

ഒരു paragraph-ന്റെ മുകളിലും താഴെയും വര വരയ്ക്കാനുള്ള സൗകര്യം. Section heading-ന് താഴെ ഒരു വര, kicker-ന് മുകളിൽ ഒരു വര — ഇതൊക്കെ ഓരോ പ്രാവശ്യവും line object വരച്ചുണ്ടാക്കേണ്ട; style-ന്റെ ഭാഗമാക്കാം. Text നീങ്ങിയാൽ വരയും കൂടെ നീങ്ങും.

Rule Above (മുകളിൽ), Rule Below (താഴെ) — രണ്ടിനും ഒരേ settings ഉണ്ട്:

Weightവരയുടെ കനം (points-ൽ)
Colourവരയുടെ നിറം
Tintനിറത്തിന്റെ ശതമാനം — 100% എന്നാൽ മുഴുവൻ നിറം, 20% എന്നാൽ ഇളം നിറം
Typesolid, dashed, dotted — വരയുടെ രീതി
Gap Colourdashed/dotted ആണെങ്കിൽ വിടവിൽ വരേണ്ട നിറം. None ഇട്ടാൽ വിടവ് സുതാര്യം
Gap Tintആ വിടവ് നിറത്തിന്റെ ശതമാനം

OverprintPrinting-ന് വേണ്ടി — press-കാർ പറഞ്ഞാൽ മാത്രം മാറ്റുക
Rule Above-ഉം Rule Below-ഉം വെവ്വേറെ on ചെയ്യാം. Headline-ന് മുകളിൽ കട്ടിയുള്ള വരയും താഴെ നേർത്ത വരയും — രണ്ടും ഒരേ style-ൽ സാധിക്കും.

ഈ വരകൾ canvas-ൽ കാണുന്നത് പോലെ തന്നെ PDF-ലും print-ലും വരും.

Paragraph Shading — പശ്ചാത്തല ബാൻഡ്

Paragraph-ന്റെ പുറകിൽ ഒരു നിറമുള്ള ബാൻഡ് ഇടാനുള്ള സൗകര്യം. Blurb, box item, "പ്രത്യേക ലേഖകൻ" പോലുള്ള ഭാഗങ്ങൾക്ക് ഉപയോഗിക്കാം. Text നീങ്ങിയാൽ ബാൻഡും കൂടെ നീങ്ങും — വേറെ rectangle വരയ്ക്കേണ്ട.

Settingഎന്ത് ചെയ്യും
Shade Onബാൻഡ് ഉണ്ടോ ഇല്ലയോ
Colour + Tintബാൻഡിന്റെ നിറവും അതിന്റെ ശതമാനവും. എഴുത്ത് വായിക്കാൻ പറ്റണമെങ്കിൽ 10–20% tint മതി
Width TypeText width അല്ലെങ്കിൽ Column width — Rules-ലേത് പോലെ തന്നെ
Top / Bottom / Left / Right Padding എഴുത്തിനും ബാൻഡിന്റെ അരികിനും ഇടയിലുള്ള ഇട
Corner Radiusബാൻഡിന്റെ മൂലകൾ എത്ര ഉരുണ്ടതാകണം. 0 എന്നാൽ കൂർത്ത മൂല
Merge Adjacentതുടർച്ചയായ paragraphs-ന് ഒരേ shading ഉണ്ടെങ്കിൽ, അവയെ ഒറ്റ ബാൻഡ് ആക്കും. Off ആക്കിയാൽ ഓരോ paragraph-നും വെവ്വേറെ ബാൻഡ്, ഇടയിൽ വിടവോടെ

Paper-masking — ബാൻഡിൽ വെട്ട് ഉണ്ടാക്കാൻ

ബാൻഡിന്റെ ഒരു മൂലയിൽ ചിത്രത്തിനോ logo-യ്ക്കോ വേണ്ടി ഒരു "വെട്ട്" (notch) വേണമെങ്കിൽ: ആ ഭാഗത്ത് Paper (വെള്ള) നിറമുള്ള ഒരു ചെറിയ shape വരച്ചിടുക. അത് ബാൻഡിന് മുകളിൽ വരും, ബാൻഡ് മുറിഞ്ഞതു പോലെ തോന്നും. ബാൻഡിന്റെ ആകൃതി മാറ്റാൻ പറ്റാത്തിടത്ത് ഇത് എളുപ്പവഴിയാണ്.

Paper നിറം page-ന്റെ നിറമാണ് — വെള്ള കടലാസിൽ അച്ചടിക്കുമ്പോൾ അത് അദൃശ്യമാകും. നിറമുള്ള background-ൽ ഈ വിദ്യ ശരിയാകില്ല.

Nested Styles

ഒരു paragraph-ന്റെ തുടക്കത്തിലെ ഒരു ഭാഗത്തിന് മാത്രം വേറൊരു character style കൊടുക്കാനുള്ള സൗകര്യം — ഓരോ പ്രാവശ്യവും കൈകൊണ്ട് select ചെയ്ത് bold ആക്കേണ്ട. Style-ന്റെ ഭാഗമായതുകൊണ്ട് എല്ലാ വാർത്തയിലും ഒരേപോലെ വരും.

ഉദാഹരണം

Dateline ഇങ്ങനെയാണ് എന്ന് കരുതുക:

കോഴിക്കോട് | സ്വന്തം ലേഖകൻ

ഇവിടെ സ്ഥലപ്പേര് (കോഴിക്കോട്) bold വേണം, ബാക്കി സാധാരണ. അതിന് ഒരു nested style rule ഇടുക:

  • Character style: Bold (നിങ്ങൾ ഉണ്ടാക്കിയ style)
  • Delimiter: | (pipe ചിഹ്നം)
  • Count: 1 — ആദ്യത്തെ | വരെ
  • Up To / Through: താഴെ കാണുക

Up To vs Through

അർത്ഥംഫലം
Up To Delimiter-ന് തൊട്ടു മുൻപ് വരെ — delimiter ഉൾപ്പെടില്ല കോഴിക്കോട് | സ്വന്തം ലേഖകൻ
Through Delimiter ഉൾപ്പെടെ കോഴിക്കോട് | സ്വന്തം ലേഖകൻ

Pipe ചിഹ്നവും bold വേണോ എന്നതാണ് വ്യത്യാസം. സാധാരണയായി Up To ആണ് വേണ്ടത്.

ഒന്നിലധികം rule

Rule-കൾ മുകളിൽ നിന്ന് താഴേക്ക് ക്രമത്തിൽ പ്രവർത്തിക്കും. ആദ്യത്തെ rule നിർത്തിയിടത്ത് നിന്ന് രണ്ടാമത്തേത് തുടങ്ങും. ഉദാഹരണത്തിന് സ്ഥലപ്പേര് bold, അതിനു ശേഷമുള്ള ലേഖകന്റെ പേര് italic — രണ്ട് rule ഇട്ടാൽ മതി.

Delimiter കണ്ടെത്തിയില്ലെങ്കിൽ ആ rule ഒന്നും ചെയ്യില്ല — paragraph പഴയപടി തന്നെ കാണും. Text-ൽ ശരിക്കും ആ ചിഹ്നം ഉണ്ടോ എന്ന് നോക്കുക.

Image Bullets

Bulleted list-ന്റെ ബുള്ളറ്റായി ഒരു ചിത്രം (PNG അല്ലെങ്കിൽ SVG) ഉപയോഗിക്കാനുള്ള സൗകര്യം — • ചിഹ്നത്തിന് പകരം പത്രത്തിന്റെ logo-യോ അമ്പടയാളമോ ഇടാം. Lists && Drop Caps tab-ൽ ആണിത്.

  1. Style-ന്റെ list type Bulleted ആക്കുക.
  2. Use image tick ചെയ്യുക.
  3. Browse അമർത്തി PNG/SVG file തിരഞ്ഞെടുക്കുക.
Settingഎന്ത് ചെയ്യും
Size mode — Auto അക്ഷരത്തിന്റെ ഉയരത്തിന് (x-height) അനുസരിച്ച് ചിത്രം താനേ വലുതാകും/ചെറുതാകും. Font size മാറ്റിയാലും ബുള്ളറ്റ് ചേർന്നു നിൽക്കും — സാധാരണ ഇതാണ് നല്ലത്
Size mode — Scale % അക്ഷര ഉയരത്തിന്റെ എത്ര ശതമാനം എന്ന് നിങ്ങൾ പറയും
Size mode — Fixed കൃത്യമായ അളവ് points-ൽ. Font size മാറിയാലും ചിത്രം മാറില്ല
V-Offset ബുള്ളറ്റ് മുകളിലേക്കോ താഴേക്കോ നീക്കാൻ. അക്ഷരത്തോട് ചേർന്ന് നിൽക്കുന്നില്ലെങ്കിൽ ഇത് ചെറുതായി മാറ്റി നോക്കുക
ചിത്രം .sla file-ന് ഉള്ളിൽ തന്നെ സൂക്ഷിക്കും (base64). അതുകൊണ്ട് file വേറൊരു കമ്പ്യൂട്ടറിലേക്ക് കൊണ്ടുപോയാലും ബുള്ളറ്റ് നഷ്ടപ്പെടില്ല — ചിത്രത്തിന്റെ original file കൂടെ കൊണ്ടുപോകേണ്ട. പകരം file size അല്പം കൂടും, അതുകൊണ്ട് ചെറിയ ചിത്രം ഉപയോഗിക്കുക.
