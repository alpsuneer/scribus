News Browser

The News Browser pulls story copy straight from the newsroom system into Scribus. Instead of copying and pasting from another window, you pick the edition and page, choose the stories you want, and drop them into a text frame. It is the third tab in the Paragraph Styles docker.

Connecting

The News Browser talks to a web API, not directly to a database. That is why it never asks for a server name, user name or password. All it needs is one API URL.

  1. Click the ⚙ (Settings) button at the top of the panel.
  2. It asks for a password. Your system administrator has it. If the password is wrong, the settings will not open.
  3. Enter the API URL — the address of the workflow server. You only need to do this once; it is remembered for next time.
  4. You can also set a default edition. If you always work on the same edition, this saves choosing it every day.

How to tell it worked: close the settings and look at the Edition dropdown. If the connection is good, it fills with edition names, and the status line below shows which edition is in use. An empty dropdown means it did not connect.

Placing a story

  1. Choose the Edition.
  2. Choose the Page.
  3. Check the Date. It defaults to tomorrow's date, not today's.
  4. Click Fetch News. The stories appear in the list below.
  5. Click any story to see a preview of it.
  6. Tick the stories you want. Select All ticks every one.
  7. On the page, select the text frame the copy should go into.
  8. Click Place Selected. The copy flows into the frame. If the story has a picture, that is placed too, with text wrap already set.
Remember: select a text frame before you click Place Selected. With nothing selected, Scribus has no way to know where the copy should go.

When something goes wrong

The Edition dropdown is empty, or you get "connection refused"
Check the API URL under ⚙ Settings. Check that the machine is on the network. The panel waits only 5 seconds for the server to answer, so if the server is slow, click 🔄 Refresh and try again.

Fetch News works but the list is empty
There are no stories for that combination of edition, page and date. Check the date first — it defaults to tomorrow, which catches people out. Then try a different edition or page.

The text comes in as boxes or garbled characters
The copy arrived correctly, but the frame's font has no Malayalam characters. Set the paragraph style on that frame to a Malayalam Unicode font, such as DBI Text. To confirm, copy the text and paste it somewhere else: if it reads correctly there, the problem is the font, not the story.

Place Selected does nothing
Check that a text frame is selected. If several objects are selected, reduce it to one.

Styles tab

This tab lists every paragraph style in the document. Click a style name to apply it to the paragraph the cursor is in, or to all the paragraphs you have selected.

Finding a style

Type in the Search styles… box at the top and the list narrows as you type. In a newspaper document with a hundred styles, this is much faster than scrolling.

The chain icon — Next Style

Some styles show a chain icon on the right of the list. That means the style has a next style set — for example 07 Byline is followed by 01 Dateline, which is followed by 03 BodyNoInd.

Click a style that has a chain icon and the whole chain is applied down the frame: the first paragraph gets the style you clicked, the second gets its next style, and so on. A full headline block can be formatted in one click.

Applying a chain is a single undo step. If it goes wrong, one Ctrl+Z puts everything back — you do not have to undo paragraph by paragraph.

Style shortcuts

Any style can be given a keyboard shortcut. In the panel's settings, click Set Key and press the key you want. From then on, pressing that key while editing text applies the style.

If the same key is assigned to two different things, Scribus fires neither of them. When that happens, go to Preferences → Keyboard Shortcuts and sort out the clash — that page shows which action currently holds the key.

Design Style tab

A Design Style builds the whole look of a story in one click. Each one can include:

  • the sequence of paragraph styles to run down the story (headline → byline → dateline → body, for example)
  • which style should be followed by a column break
  • the frame's column setup — how many columns, and the gutter
  • whether to add a picture frame, and where it sits (left, right or top), with text wrap already applied
  • a caption frame for that picture

To use one: select the text frame, then click the Design Style button. The paragraph styles, column breaks, column setup, picture frame and caption are all applied together.

Use the settings button on the tab to create and edit the presets.

Paragraph Rules

Paragraph Rules draw a line above or below a paragraph. A rule under a section heading, or above a kicker, no longer needs a separate line object drawn by hand — it becomes part of the style. When the text moves, the rule moves with it.

There are two independent rules, Rule Above and Rule Below, and both have the same settings:

SettingWhat it does
On / OffWhether the rule is drawn at all
WeightThickness of the line, in points
ColourColour of the line
TintStrength of that colour. 100% is full strength; 20% gives a pale line
TypeSolid, dashed or dotted
Gap ColourFor dashed and dotted rules, the colour in the gaps. Set it to None to leave the gaps clear
Gap TintStrength of that gap colour
Width TypeText width draws the rule only as wide as the text. Column width draws it across the full column
OffsetHow far the rule sits from the text
Left IndentHow far the rule is pulled in from the left
Right IndentHow far the rule is pulled in from the right
Keep in FrameStops the rule being drawn outside the frame
OverprintA press setting. Leave it alone unless the printer asks you to change it
Rule Above and Rule Below are switched on separately, so one style can carry a heavy rule above the headline and a hairline below it.

Rules print and export to PDF exactly as they appear on screen.

Paragraph Shading

Paragraph Shading puts a coloured band behind a paragraph. Use it for blurbs, boxed items, or standfirst lines. As with rules, the band belongs to the style, so it grows and moves with the text — there is no rectangle to keep re-drawing.

SettingWhat it does
Shade OnWhether the band is drawn at all
Colour + TintColour of the band and its strength. For text to stay readable, 10–20% tint is usually enough
Width TypeText width or column width, the same choice as for rules
Top / Bottom / Left / Right Padding Space between the text and the edge of the band
Corner RadiusHow rounded the corners are. 0 gives square corners
Merge AdjacentWhen consecutive paragraphs share the same shading, draws them as one continuous band. Switch it off to give each paragraph its own band with a gap between them

Masking a notch with Paper

If you need a notch cut out of the band — to clear a logo or a picture corner — draw a small shape filled with the Paper colour over that part. It sits on top of the band and makes it look cut away. This is the quick way to get a shape the band itself cannot make.

Paper is the page colour, so this only disappears on white stock. On a coloured background the masking shape will show.

Nested Styles

A nested style applies a different character style to the first part of a paragraph, up to a marker you choose. It saves selecting and bolding the same run of words in every story, and because it lives in the paragraph style, every story comes out the same.

Worked example

Take a dateline that reads:

സ്ഥലം | ലേഖകൻ

Here the place name (സ്ഥലം) should be bold and the reporter's name after the pipe should stay plain. Set up one nested style rule:

  • Character style: the Bold style you created
  • Delimiter: | — the pipe character
  • Count: 1 — stop at the first pipe
  • Up To / Through: see below

Up To versus Through

MeaningResult
Up To Stops just before the delimiter — the pipe stays plain സ്ഥലം | ലേഖകൻ
Through Includes the delimiter — the pipe is bold too സ്ഥലം | ലേഖകൻ

The only difference is whether the pipe itself takes the character style. Up To is what you normally want.

More than one rule

Rules run in order from the top of the list down. The second rule starts where the first one stopped. So to make the place name bold and the reporter's name italic, you use two rules.

If the delimiter is not found in the paragraph, the rule simply does nothing and the text looks unchanged. Check that the character really is in the copy — a similar-looking character will not match.

Image Bullets

Image Bullets let a bulleted list use a picture — a PNG or SVG — in place of the usual • character. Use it for a masthead device, an arrow, or a section marker. The controls are on the Lists & Drop Caps tab.

  1. Set the style's list type to Bulleted.
  2. Tick Use image.
  3. Click Browse and choose the PNG or SVG file.
SettingWhat it does
Size mode — Auto Scales the picture to the height of the lower-case letters (the x-height). Change the font size and the bullet keeps pace. This is usually the right choice
Size mode — Scale % You set the size as a percentage of that automatic size
Size mode — Fixed An exact size in points. The bullet stays that size whatever the font size is
V-Offset Nudges the bullet up or down. If it does not sit level with the text, adjust this in small steps
The picture is stored inside the .sla file. Move the document to another machine and the bullet still appears — you do not have to carry the image file with it. The trade-off is a slightly larger document, so use a small image.
